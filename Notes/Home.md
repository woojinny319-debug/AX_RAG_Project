# AX RAG Project — Knowledge Base

> 안드레 카파시의 LLM Wiki 스타일로 정리한 프로젝트 지식 베이스.  
> 모든 대화 세션과 개념은 이 홈 노트에서 연결됩니다.

---

## 📌 프로젝트 개요

이 프로젝트는 **K-IFRS 문서**와 **DART 공시 데이터**를 기반으로  
공인회계사(CPA)의 핵심감사사항(KAM) 분석을 돕는 **RAG(Retrieval-Augmented Generation)** 시스템입니다.
